## Fastest way to use it

1. Unzip this package at the root of your fork of `jaseci-labs/jaseci-blogs`.
2. Review `docs/blog/.authors.yml` before commit in case the upstream repo added new authors after this package was generated.
3. Commit and open a PR.

## Optional tweaks

- Change `name:` under `chengkj798` in `docs/blog/.authors.yml` if you want a display name instead of your GitHub username.
- Change `date:` in the frontmatter if you want the publication date to match your PR date.
